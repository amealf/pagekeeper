# Contributing

Use Node 22+. Runtime extension files live in `extension/`; no framework build or dependencies are needed. Run `npm test`, `npm run check`, and `npm run package` before proposing a release change.

Keep profiles declarative and limit permissions to the bound page. Preserve original date evidence and uncertainty. Never infer complete coverage from no new content. Do not add remote scripts, website-private API calls, credentials, telemetry or automatic uploads.

Calibrated profiles should document a public, nonsensitive example page and explain record identity, header date scope, pinned/reposted items, end/loading selectors and navigation behavior. Avoid uploading captured private pages, browser logs, tokens or actual account data. See `docs/release.md` for browser verification requirements.
