内容保存在本机

Pagekeeper 读取本次绑定页面已经加载的文本、HTML 结构、链接、标题、日期及滚动状态，并记录来源网址和观察时间。网站配置存入 Chrome 的本地扩展存储，页面记录存入本地 IndexedDB。导出文件存入你选择的下载目录。

扩展不会将网页内容上传到服务器，不包含分析统计、广告、跟踪器或外部模型服务，不读取 Cookie、密码、浏览历史或其他未绑定页面的正文。页面原本的请求和点击下一页产生的网站请求仍由网站自身处理。

权限的用途

activeTab：点击插件图标时临时访问当前页面。scripting：在绑定页面读取已加载内容并执行滚动／下一页。storage：保存网站配置和下载任务状态。downloads：保存文件并确认下载完成。可选网站权限：仅在你打开某个网站时请求该网站访问权，便于从控制页复用任务。

保留与删除

网页记录和配置保留在本机，直到你清除扩展站点数据或卸载扩展。导出的文件需要由你另行管理；卸载扩展不会删除下载文件。扩展不自动永久删除你的记录。

你可以在 Chrome 扩展设置中撤销网站权限。页面含有私人信息时，导出文件也会包含所选内容；分享前请查看文件。

源码与问题

本项目开源。问题可以提交至 GitHub Issues。提交问题时请去掉私人页面内容、账号信息与凭据。
