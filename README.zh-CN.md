# Pagekeeper · 网页翻页与存档

按网站配置滚动或点击下一页，保存浏览器已经加载的文本、链接和 HTML，确认文件下载完成后立即关闭本次来源页。

当前为 **0.1.0 预览版**，尚未提交 Chrome 应用商店。LinkedIn 配置仍需真实页面校准。

## 安装

下载发布包并解压；打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压目录。克隆仓库时选择 `extension` 文件夹。

在来源页点击插件图标，控制页会绑定这一个来源页。也可以在控制页粘贴网址并打开，Chrome 会请求这个网站的访问权限。

## 使用

选择网站配置，设置日期和翻页方式，点击「开始翻页」。需要提前结束时点击「停止并保存」。文件默认在下载目录的 `pagekeeper` 文件夹。

只有已经确认按时间倒序的列表才启用日期自动停止。相对日期按范围处理；日期未知、停止加载、达到次数／时间上限均保留真实缺口。保存失败不会自动关闭来源页。

网页存档和配置留在本机，不上传页面内容。HTML 为静态内容存档，不承诺保存原站外观、未加载图片或折叠正文。

## 扩展到其他网站

在「自定义网站配置」中修改内容块、发布日期、唯一身份、滚动区域、结束标记和下一页按钮的 CSS 选择器，另存新配置。配置可导入、导出，不必为每个网站重写插件。

浏览器助手安装后可尝试操作普通扩展控制页；此版本没有独立的 Codex 原生调用接口。网站实际结构和自动操作规则需分别确认。
