# Pagekeeper 0.1.0 preview

Configurable page turning and local archives, with a responsive Chinese control UI.

- Screen-by-screen, current-bottom, and configured next-page modes.
- Import/export site profiles and conservative date cutoffs.
- TXT, inert HTML and structured JSON exports with local recovery.
- Download-completion source-tab closing, navigation/restart guards, and partial-coverage records.
- Local-only operation with privacy documentation; no telemetry or server upload.

Download `pagekeeper-0.1.0.zip`, extract it, open `chrome://extensions`, enable Developer mode, and choose **Load unpacked** on the extracted directory. Chrome 116+ is required.

This is a **prerelease**. Installed-extension permissions, worker lifecycle and real tab closing still need real Chrome verification. The LinkedIn profile is an uncalibrated starter; no complete LinkedIn-history coverage is promised. The UI screenshots use a labelled simulated preview. Not submitted to the Chrome Web Store.
