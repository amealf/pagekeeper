# Pagekeeper contributor instructions

This is a standalone Chrome Manifest V3 extension. Keep runtime dependencies and external servers out of the extension. Do not use Next.js or import any Verdant Work project records.

Website adapters are declarative JSON; generic behavior belongs in the shared engine. Permissions are limited to activeTab and optional individual origins. A successful download must precede closing the bound unchanged source page. Preserve other tabs. Relative dates are ranges; unknown dates and loading stalls must not become complete-coverage claims.

Check affected behavior with the focused test suite and inspect the real browser UI where available. Preview mocks cannot certify an installed extension or a real site's selectors. Never publish captured pages, private evidence, logs, credentials or test-user data. Build releases with the extension-file allowlist. GitHub preview releases are distinct from Chrome Web Store approval.

Do not permanently delete user files. Before reporting progress, keep reports about actual outcomes, open limitations and user-relevant decisions. Do not add code-statistic noise.
